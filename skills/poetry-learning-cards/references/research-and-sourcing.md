# 资料与事实核查

原诗使用可靠点校本、总集或权威机构收录文本；核对篇名、作者、组诗序号、异文和标点。选择一个有依据的版本，不拼接不同版本。

诗人细节优先查正史本传、本人文集、书信、自序、同时代可信文献；必要时结合有版本依据的学术研究、年谱和权威注本。博物馆、图书馆、大学资料可帮助定位出处。搜索摘要、自媒体和无出处故事不能独立支撑卡片上的历史断言。

资料选择以“具体、有趣、能说明这个人”为标准，真实性优先于猎奇。不预设必须找到某类故事。古籍记载也须判断成书时间与性质：区分当事人记述、后世笔记、传说和现代解释。只凭作品推测性格时，用解释性措辞，不能写成确定的生平事实。

每个采用的非显然事实在 `research/` 中记录：

```text
事实或主张：
出处：书名、作者、卷/篇/页或章节；实际查阅链接或版本
依据：支持此主张的简短摘录或准确转述
性质与确定性：直接记载 / 后世记述 / 学术判断 / 有争议
使用位置与卡片措辞：
```

诗的创作年代、地点或动机若有争议，应使用“通常认为”“约”等恰当限定，或省略不必要的细节。不能由被贬经历自行推出某诗的精确写作时间与场景。画面的艺术想象也不能作为历史证据。

研究记录供家长追溯与后续修改；卡面保持易读，只有理解所必需的出处或限定才进入正文。
