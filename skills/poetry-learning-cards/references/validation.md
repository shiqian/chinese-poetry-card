# 交付检查

按封面→诗歌→诗人→背景→成语顺序打开五张实际成品检查，不能只读提示词或源文字。

1. **内容**：对照 card-contract 核实五张各尽其职；诗人有具体、有出处的记忆点，背景增加新理解，成语解释与例句语义准确。对照研究记录检查采用的事实及不确定性措辞。
2. **中文**：生成后放大查看实际图像，逐字对照 `source_text/` 定稿，检查错别字、乱码、畸形字、漏字、多字、重复文字，以及诗句顺序、异文、姓名、年代、标点、释义、例句和品牌。OCR 可辅助检查，但结果必须结合视觉复核；OCR 误识不等于图像错误，未运行也不能声称通过。发现错误或无法辨认的字，用 ImageGen 修改或重新生成，再复查该卡全部文字，防止修改引入新错。
3. **图像**：检查人物符合新设定、跨卡一致且未复制参考人物；画面与文字相符。读取五张成品的实际像素尺寸，逐张确认符合 visual-system 规定，不能只检查宽高比。正文清晰，文字面板留白充分，无裁切、遮挡、重复标题、乱码或无关水印。
4. **文件**：五张最终PNG可打开，顺序与命名正确；本套资料、文案、提示词、生成素材和预览均已归档至对应诗人诗题文件夹。

问题修正后复查受影响的卡片。若仍有无法确认的文字或事实，明确标为未完成，不将其作为可直接发布的成品交付。
