# 五张卡的内容分工

文字适合家长读给孩子听：短句、具体事物、自然中文。首次出现的必要术语随文解释。不用幼稚口吻，不为教育意义添加诗中没有的说教。控制内容量，保证手机阅读时清晰；不以缩小字号塞入研究材料。

| 卡片 | 必须呈现 | 取舍原则 |
|---|---|---|
| 封面 | 一诗一成语；《诗题》；作者：[朝代]姓名；关联成语：成语；羽言课堂 | 姓名前必须标注经核实的朝代，例如“作者：[唐]刘禹锡”；保留参考封面的五项与信息层级。 |
| 诗歌 | 诗题、朝代、作者、所选完整诗篇、诗意小课堂 | 用简明白话按诗句顺序解释，逐句或逐联对应。必要字义可融入解释；不扩写未经支持的情节。 |
| 诗人简介 | 姓名、朝代及必要身份信息；一至两个具体、可核实、令人记得住的细节 | 以冷知识或小故事为重点，体现性格、气质或人生经历；生卒年仅在可靠且有空间时列出。避免把字号、籍贯、称号、代表作堆成履历，或只说“著名、豪迈、有才华”。 |
| 背景 | 少量能帮助读懂本诗的隐含知识 | 优先解释不直接可见的历史处境、文化习惯、典故、地理或文学传统。必要时介绍创作时间地点；不重复白话诗意，也不拿显而易见的字词凑条目。 |
| 关联成语 | 成语、简明释义、一至两个例句 | 成语须真实成立，语义与诗有自然联系。例句取自孩子熟悉的家庭、学校、游戏或自然生活；展示正确用法，不只是把成语放进句子。 |

写完后检查分工：诗歌卡回答“写了什么”，诗人卡回答“这个人有什么让人记得住的地方”，背景卡回答“知道什么以后会读得更懂”，成语卡回答“生活中怎么用”。同一知识点只在最合适的一张卡展开。

## 成语例句定稿检查

生成图片前逐句检查，全部通过才写入定稿文字与生成提示词：

- **用法准确**：成语的含义、感情色彩、适用对象和语法搭配符合当前情境；有疑问时查权威词典，不凭字面猜用法。
- **逻辑成立**：人物、动作、时间和因果关系清楚合理，情境本身能体现成语的意思，不靠补充解释才说得通。
- **口语自然**：按家长读给孩子听的方式通读，检查语序、搭配和停顿；应像日常会说的话，避免生硬书面语、翻译腔及为了塞入成语而拼凑的句子。
- **具体易懂**：使用孩子熟悉的场景和词语；删去多余修饰。任何一项不通过，重写后重新检查整句。

“关联成语”不等于“出自本诗”；无可靠依据不得宣称出处。诗人生平资料稀少时，使用可证实的作品或文献细节，不虚构冷知识。佚名或集体作品仍保留第三张卡的功能，介绍可考的作者群体或传承情况，不捏造个人传记。
